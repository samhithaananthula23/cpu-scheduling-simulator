Lab procedure and reference

Aim

To simulate CPU scheduling algorithms and calculate Completion Time (CT), Turnaround Time (TAT), Waiting Time (WT), and average waiting and turnaround times.

Procedure

  1. Enter process ID, arrival time and burst time.
  2. Select a scheduling algorithm.
  3. Enter the time quantum when using Round Robin.
  4. Run the simulation and observe the Gantt chart.
  5. Verify CT, TAT and WT in the result table.

FCFS pseudo code

1. Read n processes with arrival time and burst time.
2. Sort processes by arrival time.
3. Set current_time = 0.
4. For each process:
   If current_time < arrival_time:
       current_time = arrival_time
   Start = current_time
   current_time = current_time + burst_time
   CT = current_time
   TAT = CT - arrival_time
   WT = TAT - burst_time
5. Calculate average WT and average TAT.
6. Display the Gantt chart and process table.

Key formulas

CT = time at which a process finishes. TAT = CT − AT. WT = TAT − BT.

Sample C program — FCFS

This compact reference program implements non-preemptive FCFS. It sorts by arrival time and prints the main timing values.

#include <stdio.h>
struct Process {
    int id, at, bt, ct, tat, wt;
};

int main() {
    struct Process p[20], temp;
    int n, i, j, time = 0;
    float avgWT = 0, avgTAT = 0;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    for (i = 0; i < n; i++) {
        p[i].id = i + 1;
        printf("Enter AT and BT for P%d: ", i + 1);
        scanf("%d%d", &p[i].at, &p[i].bt);
    }

    /* Sort by arrival time */
    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (p[i].at > p[j].at) {
                temp = p[i]; p[i] = p[j]; p[j] = temp;
            }

    for (i = 0; i < n; i++) {
        if (time < p[i].at) time = p[i].at;
        time += p[i].bt;
        p[i].ct = time;
        p[i].tat = p[i].ct - p[i].at;
        p[i].wt = p[i].tat - p[i].bt;
        avgWT += p[i].wt;
        avgTAT += p[i].tat;
    }

    printf("\\nPID\\tAT\\tBT\\tCT\\tTAT\\tWT\\n");
    for (i = 0; i < n; i++)
        printf("P%d\\t%d\\t%d\\t%d\\t%d\\t%d\\n",
            p[i].id, p[i].at, p[i].bt,
            p[i].ct, p[i].tat, p[i].wt);

    printf("Average WT = %.2f\\n", avgWT / n);
    printf("Average TAT = %.2f\\n", avgTAT / n);
    return 0;
}

Frequently asked questions

What is CPU scheduling?

It is the method used by the operating system to select a process from the ready queue and allocate the CPU to it.

What is the difference between TAT and WT?

Turnaround time is the total time from arrival to completion. Waiting time is the time spent waiting in the ready queue.

Which algorithm can cause starvation?

SJF and priority scheduling can cause starvation when long or low-priority processes keep getting postponed.

Why is Round Robin used?

It gives each ready process a fixed time quantum, making it useful for time-sharing systems.

What is a Gantt chart?

It is a timeline showing which process uses the CPU during each time interval.

What does MLFQ mean here?

This teaching model uses two queues: a high-priority queue with a short quantum and a lower-priority queue with a longer quantum. It is a simplified MLFQ model, not every OS-specific variant.
